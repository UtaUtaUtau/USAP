# USAP: UnderStandable Alphabet of Phonemes

[Filipino](README.md)

USAP is a phonetic alphabet for the Filipino/Tagalog language. This is made with vocal synthesizers in mind, but usage in other applications is encouraged.

The main inspiration for this alphabet comes from [ARPAbet](https://en.wikipedia.org/wiki/ARPABET), from its simple and intuitive alphabet for American English. This philosophy can be seen from the direct match of the phonemes to Filipino orthography. As a result, almost all words have similar-looking representations in this alphabet.

# Contents

The phonemes and their X-SAMPA and IPA counterparts can be seen in this [document](PHONEMES.md). Example words where the phoneme is present can also be seen here.

Included in the releases is a [phonetic dictionary](https://github.com/UtaUtaUtau/USAP/releases) that uses this alphabet. This follows the format of [CMU Pronouncing Dictionary](http://www.speech.cs.cmu.edu/cgi-bin/cmudict), using tab as a separator instead of two-spaces. The pronunciations are obtained from [wikipron](https://github.com/CUNY-CL/wikipron). Because of this, the license of the dictionary is CC BY-SA 4.0 instead of CC0.
