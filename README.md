# USAP: UnderStandable Alphabet of Phonemes

[English](README.en.md)

Ang USAP ay isang alpabeto ng mga ponema para sa wikang Filipino/Tagalog. Ginawa ito para sa mga vocal synthesizers, ngunit hinihikayat ang paggamit nito sa ibang pagsisikap.

Ang pangunahing inspirasyon ng alpabetong ito ay galing sa [ARPAbet](https://en.wikipedia.org/wiki/ARPABET), dahil sa simple at madaling maunawaan na alpabeto nito para sa American English. Makikita ang pilosopiyang ito sa direktang pagtutugma ng mga ponema sa pagsulat ng wikang Filipino. Dahil dito, halos lahat ng mga salita ay kapareho ng kaniyang representasyon sa alpabetong ito.

# Mga Nilalaman

Ang mga ponema at ang kanilang mga katumbas sa X-SAMPA at IPA ay mahahanap sa [dokumentong ito](PONEMA.md). Kasama rin dito ang mga halimbawang salita kung saan maririnig ang ponema.

Makikita sa releases ay isang [diksyunaryo ng pagbigkas](https://github.com/UtaUtaUtau/USAP/releases) na gumagamit ng alpabetong ito. Sinusundan nito ang format ng [CMU Pronouncing Dictionary](http://www.speech.cs.cmu.edu/cgi-bin/cmudict), gamit ang tab bilang separator sa halip na dalawang espasyo. Ang mga pagbigkas na ito ay kinuha mula sa [wikipron](https://github.com/CUNY-CL/wikipron). Dahil dito, ang lisensya ng diksyunaryong ito ay CC BY-SA 4.0 sa halip na CC0.
